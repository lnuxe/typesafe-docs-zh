# 常量

> TypeSafe Python SDK 的默认设置与环境变量名。

<a id="constants" />

<h2 id="typesafe_sdk.constants">
  typesafe\_sdk.constants
</h2>

公开的环境变量名与客户端默认值。

<h3 id="typesafe_sdk.constants.API_KEY_ENV">
  API\_KEY\_ENV
</h3>

`module-attribute`

```python theme={null}
API_KEY_ENV = 'TYPESAFE_API_KEY'
```

API 密钥的环境变量。

<h3 id="typesafe_sdk.constants.BASE_URL_ENV">
  BASE\_URL\_ENV
</h3>

`module-attribute`

```python theme={null}
BASE_URL_ENV = 'TYPESAFE_BASE_URL'
```

API 基础 URL 的环境变量。

<h3 id="typesafe_sdk.constants.DEFAULT_MODEL_ENV">
  DEFAULT\_MODEL\_ENV
</h3>

`module-attribute`

```python theme={null}
DEFAULT_MODEL_ENV = 'TYPESAFE_DEFAULT_MODEL'
```

默认模型的环境变量。

<h3 id="typesafe_sdk.constants.LOG_LEVEL_ENV">
  LOG\_LEVEL\_ENV
</h3>

`module-attribute`

```python theme={null}
LOG_LEVEL_ENV = 'TYPESAFE_LOG_LEVEL'
```

日志级别的环境变量。

<h3 id="typesafe_sdk.constants.DEFAULT_BASE_URL">
  DEFAULT\_BASE\_URL
</h3>

`module-attribute`

```python theme={null}
DEFAULT_BASE_URL = 'https://api.typesafe.ai'
```

默认的 API 基础 URL。

<h3 id="typesafe_sdk.constants.DEFAULT_MODEL">
  DEFAULT\_MODEL
</h3>

`module-attribute`

```python theme={null}
DEFAULT_MODEL = 'jev-latest'
```

默认模型名称。

<h3 id="typesafe_sdk.constants.DEFAULT_TIMEOUT">
  DEFAULT\_TIMEOUT
</h3>

`module-attribute`

```python theme={null}
DEFAULT_TIMEOUT = 10.0
```

每个 HTTP 操作的默认超时秒数。
